## 📖 소개

문명이 붕괴한 세계에서 생존을 시작합니다. 세계 지도에서 지역과 장소를 고르고, 그곳에서 벌어지는 사건과 인물을 만나며 선택지를 고릅니다. 선택은 **체력·정신력·아이템·인물 관계**에 영향을 주고, 이후 이야기와 엔딩을 바꿉니다.

화려한 액션보다 **텍스트, 선택, 분위기, 탐험**에 집중한 게임입니다.

## ✨ 특징

- 🗺️ **지도 중심 탐험**: 지역 → 장소를 직접 골라 이동
- 📜 **세 가지 이벤트 조합**: 고정 · 랜덤 · 조건부 이벤트
- 🧠 **정신력이 곧 분위기**: 정신력이 낮아지면 묘사와 선택지가 달라집니다
- 🎒 **쓸모 있는 아이템**: 손전등, 열쇠 등이 새 선택지를 엽니다
- 🤝 **기억하는 인물들**: 도와준 사람은 돌아와 도와주고, 외면한 사람은 등을 돌립니다
- 🎭 **멀티 엔딩**: 진행하며 쌓인 선택이 결말을 가릅니다
- 💾 **자동 저장**: 브라우저에 진행 상황이 저장됩니다

## ▶️ 플레이

| 방법 | 설명 |
|---|---|
| **로컬** | `index.html`을 브라우저로 열기 (서버 불필요) |
| **GitHub Pages** | 저장소 업로드 → `Settings → Pages → Branch: main / (root)` → `https://<아이디>.github.io/<저장소>/` |

## 🎮 진행 방식

```
지역 선택 → 장소 선택 → 이벤트 발생 → 텍스트 확인 → 선택 → 결과 적용 → 다음 탐험
```

| 능력치 | 범위 | 설명 |
|---|---|---|
| ❤️ 체력 | 0 ~ 10 | 0이 되면 탐험 실패 |
| 🧠 정신력 | 0 ~ 10 | 낮을수록 묘사가 변하고, 0이 되면 정신 붕괴 |


## 🧭 현재 범위 (1차 프로토타입)

| 구분 | 수량 |
|---|---|
| 지역 | 구도심 1개 (나머지 4개는 잠김) |
| 탐험 장소 | 5 |
| 일반 이벤트 | 10 |
| 스토리 이벤트 | 3 |
| NPC | 2 (민재, 노인 상인) |
| 아이템 | 10 |
| 엔딩 | 3 + 탐험 실패 |
