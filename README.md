# WASTELAND

낡은 종이에 그린 흑백 스케치 스타일의 **텍스트 기반 탐험·생존 RPG**. 웹 브라우저에서 플레이하는 싱글 플레이 게임입니다.

문명이 붕괴한 세계에서 지도를 보고 탐험할 장소를 고르고, 그곳에서 벌어지는 사건을 읽고 선택합니다. 선택은 체력·정신력·아이템·인물 관계와 엔딩에 영향을 줍니다.

## 플레이

- **웹**: GitHub Pages 주소에서 바로 실행
- **로컬**: 저장소를 받아 `index.html`을 브라우저로 열기 (설치·서버 불필요)

진행 상황은 브라우저에 자동 저장됩니다.

## 현재 상태 (1차 프로토타입)

구도심 1개 지역 · 탐험 장소 5 · 이벤트 13 (스토리 3 포함) · NPC 2 · 아이템 10 · 엔딩 1(탐험 실패)
구도심 스토리를 끝내면 산업지대가 해금됩니다 (산업지대 콘텐츠는 개발 예정).
나머지 4개 지역(산업지대, 호수, 신도시, 산악지대)은 개발 예정입니다.

## 구조

```
index.html       화면 (타이틀 + 게임)
assets/world/    지도 이미지 (main_map_01.jpg)
css/style.css    UI 스타일
js/engine.js     게임 로직
js/sound.js      효과음(WebAudio)·사운드 설정
data/world.js    지역 · 장소 · 아이템 · 엔딩
data/events.js   이벤트
```

콘텐츠는 `data/` 폴더만 수정하면 추가할 수 있습니다. 이벤트 형식은 `data/events.js` 상단 주석을 참고하세요.

## 기술

HTML / CSS / JavaScript (프레임워크·빌드 도구 없음)

## 엔딩 화면 이미지

엔딩마다 전용 이미지를 넣으려면 `assets/endings/엔딩id.jpg` 파일을 올리면 됩니다 (권장 1600×900, 16:9). 그리고 그 id를 `data/world.js`의 `window.GAME_DATA.endingImages = ["launch", ...]` 배열에 추가해야 표시됩니다 (없는 파일을 요청해 404가 나는 것을 막기 위함). 목록에 없으면 지도 확대 그림이 임시로 쓰입니다.
엔딩 id 목록은 `data/world.js`의 `endings`에 있습니다. (예: `launch.jpg`, `death_mtn.jpg`)



## 판마다 달라지는 요소 (v2)

- **지역 순서**: 새 게임마다 구도심 → (산업지대·호수·신도시를 섞은 3곳) → 산악지대 순서가 달라집니다. `S.route`에 저장됩니다.
  글 안에서 `{R1}`~`{R3}`(이번 판의 1~3번째 지역), `{next}`(지금 지역의 다음 지역), `{next:으로}`(조사 자동 선택)를 쓰면 이번 판 이름으로 바뀝니다. 단서 아이템에는 `of: "지역id"`를 붙이면 `{next}`의 기준이 됩니다.
  결과의 `unlock`은 지역 id와 상관없이 "지금 지역의 다음 지역"을 엽니다.
- **하루 3칸**: `data/world.js`의 `actMax`. 하루가 끝나면 밤 단계(식사 선택 `meals` → 밤 이벤트 `nights`)를 거칩니다.
- **인물 이야기**: `data/events.js` 아래쪽 `N(id, stage, ...)`. `stage`는 이번 판의 몇 번째 지역인지(0=구도심, 1~3, 4=산악지대)이고 배열도 됩니다. `D.cast`에 등록한 인물은 `with` 깃발이 켜지면 벙커 화면에 '동행'으로 표시되고, 멀쩡하면 환경 피해를 줄여 줍니다.
- **환경 피해(ambient)**: 지역 이름이 아니라 몇 번째로 간 지역인지(`ambientStage`)로 강해집니다.
